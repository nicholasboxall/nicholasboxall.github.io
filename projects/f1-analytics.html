Formula 1 Performance Analytics

An exploration of Formula 1 race performance and telemetry, investigating driver performance, lap times, tyre strategies and vehicle data.

Project Overview

As a Formula 1 fan with an interest in data analytics, I undertook this project to gain a deeper understanding of the intricacies of a Formula 1 race weekend and explore underlying performance metrics that are not always visible during live broadcasts.

While much of this data and analysis is available through paid third-party platforms, I discovered the FastF1 Python package, which allowed me to access session data and develop my own analytical tools and interactive dashboards for a more detailed and personalised exploration of the sport.

Data access note: As of October 2026, accessing Formula 1 session data through FastF1 requires an F1 TV Access subscription or higher.

Python visuals note: Unfortunately, python visuals are unable to be viewed in publish to web Power BI. If you wish to see the full working, please contact me and I can send the original file.

Tools and Technologies

For this project, I utilised FastF1 to extract Formula 1 session data and native Python to clean the data. After this, I uploaded data to an SQL Server, where it can be accessed by Power BI and be quickly refreshed to include new data.

FastF1 --> Python --> SQL Server --> Power BI
