Complex Newton's Method Fractals

View Source Code on GitHub →

Project Overview

An application which uses Newton's Method to:

  • Plot the function along the real axis.
  • Find all complex roots of the function.
  • Plot all complex roots on the complex plane.
  • Generate a fractal pattern showing which root each region of the complex plane converges towards.

Tools and Technologies

For this project, I used Python Code alongside the Numpy and Matplotlib packages.
