Project Overview

The complex plane differs from the standard Cartesian plane as it contains both real and imaginary axes. A large subset of functions contain at least one complex value root and using purely real mathematics, they are impossible to find. In order to proceed, this project uses the formula for imaginary numbers denoted by,

\[ i^2 = -1 \]

Newton's Method is an iterative numerical method which takes a certain value and function as an input and attempts to estimate the roots of the function. It does so by drawing a tangent line at your starting point, and outputting the point where that line intersects the y-axis. Then repeat the process as many times as you wish, ideally until your next estimate doesn't differ from the last by a significant amount or tolerance.

The formula for Newton's Method:

\[ z_{n+1} = z_n - \frac{f(z_n)}{f'(z_n)} \]

In this project, I have designed an application which uses Newton's Method to:

  • Plot the function along the real axis.
  • Find all complex roots of the function.
  • Plot all complex roots on the complex plane.
  • Generate a fractal pattern showing which root each region of the complex plane converges towards.
