NSW Road Safety Analysis

Geographic and statistical analysis of road crashes across New South Wales, investigating crash patterns, injury severity and geographic hotspots.

View Source Code on GitHub →

Project Overview

This project combines Power BI, Python and QGIS to explore road crash trends and identify high-risk locations across NSW by both frequency and severity.
